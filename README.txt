EXIE — Express Innovation Enterprise Public Website
===================================================

This is a responsive static website for EXIE, a private service provider based in Bend and Stop, Barnesville, Liberia. It uses HTML, CSS, JavaScript, and local image assets. It does not require a database or server-side runtime.

FILES
- index.html: website content, services, FAQs, official links, contact details, and notices
- styles.css: visual design, responsive layouts, and accessibility polish
- script.js: expandable navigation and current copyright year
- assets/images/: EXIE logos, supplied testimonial posters, studio/generator imagery, and pricing-card images

PREVIEW LOCALLY
1. Extract the ZIP.
2. Open the EXIE_Public_Website folder.
3. Open index.html in a browser.
4. Test the navigation and links at desktop and mobile widths.

UPLOAD TO HOSTING
1. Open your hosting control panel's File Manager.
2. Open the document root assigned to your domain (often public_html).
3. Upload the contents of EXIE_Public_Website so index.html is directly inside the document root.
4. If uploading this ZIP, extract it and make sure the site files are not nested one folder too deep.
5. Open the live website on a phone and computer and test all links.

BEFORE PUBLIC LAUNCH
- Confirm the service charges, especially what the additional US$2.00 covers. Do not publish a total that customers could misunderstand.
- Confirm contact numbers, WhatsApp accounts, and the location wording.
- Publish customer testimonial posters only with appropriate permission to use names, photos, and statements.
- Review every official DV-program statement against the current year's U.S. Department of State instructions. Program rules and eligibility can change.
- Confirm that the website works on your domain after uploading. This project has not been connected to a backend or a live domain.
